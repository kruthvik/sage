# Learning-engine implementation map

## Foundation to preserve

Pi's isolated native terminal, resource loader, update/rollback mechanism and bounded planning child remain the conversational/model authority. Bun's four educational operations persist immutable revisions/events in seven SQLite tables. Exact task/rubric revisions, captured learner responses, assistance exposure, source consent, idempotency, correction chains and WAL-safe backups already work. Projections are disposable, not canonical ability records.

2. SQLite migration 2 adds query indexes only, keeps all seven tables and immutable history. Update restore compatibility. Projector 2 retains legacy observation arrays while adding separate evidence summaries, support uncertainty, guidance, exposure, hypotheses and coverage debt.
3. Add deterministic review proposals and small candidate sets; Pi selects actions, records reasons and may override defaults. Scope context to the active outline/task, bound each summary and support ID-based drill-down. No model client in storage/runtime state.
4. Extend the existing source operation with capability discovery and bounded local calculation/graph/drawing actions. A declarative adapter registry distinguishes available, unavailable and permission-denied tools. Tutor artifacts never prove learner performance; model interpretation remains inferred. No arbitrary code execution or fake connected Desmos/voice service.
5. Add derived evaluation reports and end-to-end policy fixtures. Restore a public `brain.md` template; copy it only into new homes, never overwrite personal notes.

Primary modules: core/contracts + learning types; storage/store + projection; runtime/context + candidates + review + evaluation; integrations registry/adapters; Pi tool descriptions/policy; CLI maintenance; bootstrap, backup, publication guard and documentation.

## Research-to-policy boundary

Read main.md, corrected learning-science-final.md, evidence reviews 02–08, research contract, critique and integrated synthesis. Ignore outputs/start.md. Retrieval/spacing have support for many delayed-recall tasks, with failure/feedback and domain boundaries. Examples/fading, contrast, mixing, explanation and transfer are conditional. The critique distinguishes representation sequencing from problem-type mixing and preserves the physics midterm null. Confidence, immediate success and activity counts are not durable ability. The corpus is incomplete and cannot validate an optimal controller.

The candidate priority order, guidance triggers, review intervals and hypothesis update rules below are inspectable engineering defaults, not calibrated psychometrics. No technique quotas, learning styles, fabricated time-based forgetting, permanent misconception labels or universal mastery threshold. Changed numbers are not broad transfer. Acquisition, independent performance, delay, changed application, method selection and explanation stay separate.
